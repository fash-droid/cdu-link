# cdu-link

Halaman pengalih permanen menuju aplikasi **Keandalan CDU RU VI Balongan**.

Alamat aplikasi di belakang bisa berubah karena memakai Cloudflare Tunnel gratis.
Halaman GitHub Pages ini membaca `url.json` yang selalu dibarui otomatis oleh
PC server, lalu meneruskan pengunjung ke alamat aktif.

**Bookmark URL ini, bukan URL tunnel:**
https://fash-droid.github.io/cdu-link/

Isi `url.json` diperbarui oleh skrip PowerShell di `KP Pertamina/deploy/` yang
berjalan sebagai autostart Windows di komputer server.
